# 开源项目

个人开发的开源工具集合。

## 项目列表

### 🔋 功耗计算器

嵌入式设备电池续航时间与电池容量的**在线估算工具**，专为硬件设计前期评估阶段打造。

- 多种计算模式：续航时间 / 所需电池容量
- 多种电池类型：锂电池、锂亚电池、碱性干电池
- 多工作模式配置，自动计算休眠时长
- 图表可视化：柱状图 + 环形图展示能耗分布

[查看详情 →](/open-source/power-calculator/)

### 🧪 气体浓度换算

可燃气体 %VOL、ppm、%LEL 浓度单位在线换算工具，支持 8 种常见可燃气体。

- 三种单位互转：%VOL、ppm、%LEL
- 8 种常见可燃气体预设
- C / Python / Web 三端实现

[查看详情 →](/open-source/gas-converter/)

### ⏰ 时间戳转换

Unix 时间戳（秒/毫秒）与日期时间互转的在线工具，支持多时区与批量转换。

- 双向转换，秒级/毫秒级精度自动识别
- 38 个常用时区，支持城市/偏移搜索
- 多格式输出与批量转换，完全本地处理

[查看详情 →](/open-source/timestamp-converter/)
