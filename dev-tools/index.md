# 开发工具

常用开发调试工具集合，覆盖 JSON、Base64、时间戳等高频场景。**所有工具均在浏览器本地运行**，数据不会上传到任何服务器。

## 数据 & 文本

### 📄 JSON 格式化

在线 JSON 格式化与校验工具，美化缩进、语法高亮、错误定位、一键压缩。

- 2/4 空格缩进切换，键/字符串/数字语法高亮
- 解析失败定位到具体行、列
- 完全本地处理，支持离线使用

[查看详情 →](/dev-tools/json-formatter/)

### ⏰ 时间戳转换

Unix 时间戳（秒/毫秒）与日期时间互转工具，自动识别精度，支持 38 个常用时区与批量转换。

- 双向转换，秒级/毫秒级精度自动识别
- 38 个常用时区，支持城市/偏移搜索
- 多格式输出与批量转换，完全本地处理

[查看详情 →](/dev-tools/timestamp-converter/)

📖 [Unix 时间戳完全指南：转换、精度与时区 →](/dev-tools/timestamp-converter-guide/)

## 编码 & 安全

### 🔤 Base64 编解码

UTF-8 文本与 Base64 字符串互转工具，支持文件转 Data URI。

- 文本与 Base64 双向转换，UTF-8 完整支持
- 文件转 Base64（Data URI），可直接用于图片嵌入
- 输入输出一键交换，完全本地处理

[查看详情 →](/dev-tools/base64/)
