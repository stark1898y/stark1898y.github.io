# 知识库简介

欢迎来到 **Stark1898y 的个人知识库**！

这是一个专注于嵌入式开发的技术知识库，记录日常学习和工作中的技术笔记、经验总结。

## 知识分类

### [硬件设计](/docs/hardware/tools)

电源、接口、保护器件、常用器件、无线通信等硬件相关知识。

### [MCU 开发](/docs/mcu/)

- **[STM32](/docs/mcu/stm32/cubemx)**：STM32 系列 MCU 开发
- **[WCH RISC-V](/docs/mcu/ch32v/gcc-toolchain)**：CH32V 系列 RISC-V MCU 开发
- **[BLE 蓝牙](/docs/mcu/ble/ble-stack)**：CH592、CH584 等 BLE 芯片开发

### [软件开发](/docs/software/framework/bare-metal)

框架架构、常用组件、存储方案、通信协议、升级方案等嵌入式软件知识。

### [RTOS 系统](/docs/rtos/comparison)

RT-Thread、FreeRTOS 等实时操作系统的学习笔记。

### [开发工具](/docs/tools/ide/keil-mdk)

Keil MDK、MounRiver Studio、VS Code 等开发工具的使用技巧。

### [Linux 开发](/docs/linux/basics)

Linux 基础、驱动开发、交叉编译等知识。

### [AI & Python](/docs/ai-python/python-basics)

Python 基础、机器学习、AI 工具等学习笔记。

### [学习资源](/docs/resources/blogs)

推荐博主、常用网站、推荐书籍等学习资源汇总。

### [开源项目](/open-source/)

功耗计算器、气体浓度换算等自研在线工具。

## 内容来源

- 个人学习笔记
- 工作经验总结
- 优秀博客文章整理
- 官方文档摘录

3. 点击链接查看相关资源
